# VibeTrack — OpenCode Rules

## After every set of changes

1. **Fix all linting issues** before committing (`npm run lint` or equivalent).
2. **Write tests** for any new logic or components where possible.
3. **Run tests** and ensure they pass before committing (`npm test` or equivalent).
4. **Commit** all changes with a descriptive commit message.
5. **Push** to the remote repository.

This sequence is mandatory — do not skip any step.
